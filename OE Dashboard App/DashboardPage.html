How to read this: Every column counts bids by Bid Deadline date in that window and follows the same set through the stages, so each conversion is a true forward conversion. Windows are calendar-based and anchored on yesterday so the team has time to work the inbox — deadlines after yesterday are excluded, making every window period-to-date: Daily = yesterday · Weekly = Monday through yesterday · Monthly = 1st through yesterday · Q1–Q4 = calendar quarters of the current year (the current quarter runs through yesterday; future quarters fill in once they start) · YTD = Jan 1 through yesterday. "In progress" = board bids not yet submitted. Gray "created" lines count the same window by Created date — when the BD Managers accepted the invite into Basis — with no deadline filter, so they include live bids whose deadlines haven't hit yet. Data refreshes from BasisBoard daily at ~4am; this page recomputes on every reload.
